# 栖流 Flowhome v1 — 交付验收与限制

日期：2026-09-18。验收对象是可演示的研究MVP，不是真实城市服务或经营成效。三个研究角色分别使用 gpt-6-astra（算法审查）、gpt-5.6-sol（品牌叙事）、gpt-5.6-terra（独立验收），情境图由 gpt-5.6-luna 协调生成；主代理负责集成、修正与发布。

## 交付范围

六个交互视图：城市运行台、我的居住计划、物件的一生、共益运营、策略实验室、关于栖流；八段故事导航；一个可复现逐周计算内核；120次固定对照、90次敏感性结果；品牌和模型说明；全部使用模拟数据。

## 运行与性能证据

11项独立引擎测试覆盖确定性、未来信息隔离、取消与承诺、现金与所有权、容量、床垫拒绝、新人、可兑现排序、提前匹配价格、二手维护成本、实体引用。测试由 Node test runner 执行。

桌面：托管云端 Chrome，约1350×926视口；宿主CPU型号不可见。页面显示的Worker三策略计算耗时（秒）：0.65、0.58、0.59、0.55、0.59、0.64、0.57、0.53、0.59、0.52。10/10低于3秒；该数值不包括首次页面网络加载。固定实验文件另含10次Node三策略基准。增加SKU集中度诊断后重新运行固定实验，实际数据以JSON为准。

浏览器批量操作观察到38/120等进度，中途能切换到“关于栖流”，最终显示“当前参数批量运行”。六页手机阅读通过同源390×844 iframe视口检查：页面clientWidth与scrollWidth均为375（另外15px为滚动条）。标签栏和表格可局部横向滚动；这不是实体手机触屏或Safari兼容测试。

WebMCP工具已做特性检测、输入验证与生命周期清理；当前浏览器报告document.modelContext不可用，因此运行验证不可用，不能宣称工具调用验收通过。普通界面不依赖它。

动态JSON导出按钮已实现标准Blob下载；浏览器自动化未捕获到download事件，不能确认该自动化通道完成文件保存。固定实验原始JSON与所有说明文档随网站静态提供，作为可直接打开的交付件。

## 实验结论（固定参数、合成数据）

正常情景10个种子平均：B0满足率81.44%、循环380.2次、期末现金80,033元；B2满足率80.95%、循环334.7次、期末现金14,139.1元。该初版并未显示预测协调整体更优。回购把退出风险从个人转给组织，需要资本和可复用服务；更高采纳率或乐观预测可能进一步占用现金。B1的局部提前预约也没有在本实验中胜出，不能把“提前”本身当作提升保证。

这些是策略组合的差异，不是AI净因果效果。模型固定费用偏简化，所谓“扣固定费后结果”仍不包含真实完整团队、税费和获客成本；不能据此认定商业可行。

优先验证：青年是否愿意为退出确定性付费；真实检测/搬运/耗材成本；长期资金周转；低预算群体的进入门槛；按品类预测误差；服务方责任和申诉组织。下一轮增加推荐/回购的消融对照及型号级供需预测。现阶段不开展真实回购、租赁、信用筛选或用户付款。
