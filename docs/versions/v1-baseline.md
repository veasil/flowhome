## 发现的问题

1. 提前匹配先挑最低价，再检查交付期限，可能因首选无法按时交付而跳过其他可行二手候选。临时内存对照只增加`ready+2<=deadline`过滤，B1正常情景平均循环交付336.4→383.6，B2为334.7→383.3；原B0为380.2。满足率B1为80.96%→81.04%，B2为80.95%→81.03%，仍不代表全面胜出。该临时修正未写回已发布代码，须在v2回归后重新实验。
2. 随机居民只在W0—77产生新需求，城市却运行到W103。默认运行W77之后无新增需求、仍有78笔回购，形成特殊的市场退出尾段。不能拿它代表稳定流动的城市。
3. B0与B2同时改变预测、选品、回购责任和资金占用，不能把差值归因于预测。
4. 退出确定性、处置时间、购买顾虑没有得到行为建模；承担保障成本却没有充分度量目标收益。
5. 界面按主题组织，混合了消费者、服务商、平台运营与研究者，未形成清晰的角色工作流。
